# アイデアシート テンプレート

壁打ちの結果を以下の形式でまとめて提示してください。埋まらない項目は空欄のまま残し、「次に検討すること」に挙げてください。

```markdown
# プロジェクトアイデア: {プロジェクト名（仮）}

## 課題とユーザー
- 対象ユーザー:
- 解決する課題・実現したい価値:
- 現状の代替手段とその不満・物足りなさ:

## ソリューション
- 概要（3行以内）:
- エージェントが自律的に行うこと（観察→判断→行動の流れ）:
- ガバナンス・セキュリティの考慮（エージェントの行動制御・監査など）:

## 実現構成
- 実行プロダクト（App Engine / GCE / GKE / Cloud Run / Cloud Functions / Cloud TPU・GPU から1つ以上）:
- AI技術（Vertex AI / Gemini API / Gemma / Imagen / Agent Builder / ADK など1つ以上）:
- アーキテクチャ案（構成要素と接続を箇条書きで）:

## スコープ
- ハッカソンで作るもの（MVP）:
- 時間が余ったら足すもの:
- 作らないと決めたもの:

## リスク・次に検討すること
-
```

## まとめ方の注意

- 「エージェントが自律的に行うこと」が単発の質問応答になっていないか、提示前に再確認する
- 実現構成の必須要件（実行プロダクト・AI技術）が埋まっていない場合は、その旨を明示して選定の相談を促す
- シートはダッシュボードのプロジェクト概要（プロジェクト名・概要・ソリューション説明・アーキテクチャ説明）の下書きとして使えることを参加者に伝える
